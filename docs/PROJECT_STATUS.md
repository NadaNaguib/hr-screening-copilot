## Deficit & Failure Register (Identified Bugs, Gaps & Unachieved Specs)

This register provides an unvarnished audit of all failures, architectural compromises, and unachieved features identified in the current system:

| Deficit ID | Category | Deficit / Failure Description | Severity | Root Cause & Evidence | Impact & Interim Mitigation |
|---|---|---|---|---|---|
| **DEFICIT-01** | **Evaluation** | Q-23 *"Are there any candidates who have worked at startups?"* scores `0.33` (FAIL). | Medium | Seeded CV texts in PostgreSQL contain 0 occurrences of `"startup"`. Because the Agentic RAG synthesis is strictly grounded to prevent hallucinations, the LLM truthfully reports no startup experience. | Live eval score is **0.88** (not 1.00). Mitigation: Add startup experience to candidate seed data (`scripts/seed_full_candidates.py`). |
| **DEFICIT-02** | **Evaluation / RAG** | Q-22 *"Which candidate has the highest rubric score for the backend role?"* scores `0.75`. | Low | Query router in `orchestrator.py` classifies `"rubric"` as `is_job_inquiry` and fetches rubric criteria definitions instead of candidate scoring records (`overall_score`). | Model lacks candidate scores in context. Mitigation: Route score inquiries to `candidate_evaluation_reader` or `list_candidates_for_job`. |
| **DEFICIT-03** | **Testing / DevOps** | Default `pytest` execution fails with `[Errno 111] Connect call failed ('127.0.0.1', 5432)`. | High | `docker-compose.yml` does not expose PostgreSQL port `5432` to the host machine (`ports: ["5432:5432"]` is missing from `db` service). | Local developer `pytest` fails without explicit DB URL override. Mitigation: Execute with `TEST_DATABASE_URL="postgresql+asyncpg://copilot:copilot@<container-ip>:5432/hr_screening_test"`. |
| **DEFICIT-04** | **Testing** | Missing Docker container test suite execution. | Medium | `Dockerfile` runtime stage does not copy `tests/`, and `docker-compose.yml` does not mount `./tests:/app/tests:ro` into the `api` container. | `docker exec hobby-api-1 pytest` collects 0 tests. Tests must be executed from the host venv. |
| **DEFICIT-05** | **Testing** | Empty contract test suite (`tests/contract/` has 0 tests). | Medium | `tests/contract/__init__.py` exists but contains no contract tests for Clean Architecture ports/adapters. | Interface contract compliance is not validated automatically in CI. |
| **DEFICIT-06** | **Testing** | Low automated test suite coverage (~35% line coverage). | Medium | Only 19 unit/integration test cases exist in the repository; large portions of repository adapters and routers lack automated test cases. | Violates NFR-06 enterprise target of $\ge 80\%$ test coverage. |
| **DEFICIT-07** | **Code Quality** | Strict type-checking failures (`mypy` reports 158 errors). | Low | `mypy` strict mode enabled in `pyproject.toml`, but presentation routers use untyped `dict` arguments and some missing return types. | Violates NFR-06 strict type annotation mandate. |
| **DEFICIT-08** | **Code Quality** | Linter violations and async blocking file I/O (`ruff` reports 32 errors). | Medium | Synchronous `open()` and `os.path.exists()` calls inside async FastAPI route handlers (`ASYNC230`, `ASYNC240` in `candidates.py`). | Can block the asyncio event loop under high concurrent I/O load. Mitigation: Refactor to `aiofiles`. |
| **DEFICIT-09** | **Architecture** | Target Enterprise Architecture gaps (9 deferred components). | Low (By Design) | Kong Gateway, Kafka Event Bus, HashiCorp Vault, EKS KEDA Autoscaling, Redis Cluster, Dedicated OpenSearch/Milvus, Datadog APM, Multi-Region DR, Okta SSO are deferred in MVP. | Documented in `docs/SYSTEM-DESIGN.md` Gap Analysis Table with estimated 3-year enterprise cost of $490,664. |
| **DEFICIT-10** | **UI / Product** | Review Queue lacks real-time push updates; Shortlist PDF missing UI trigger. | Low | Review Queue relies on manual refresh / periodic polling instead of WebSockets/SSE; Shortlist PDF export is implemented in backend ReportLab but lacks button in UI. | Reviewers must refresh page to see updated SLA escalation or assigned tasks. UI only triggers CSV export. |

## What Has Been Achieved vs. What Has Not Been Achieved

### What Has Been Achieved ✅
1. **Full Functional Core (Variant D6 + T5)**:
   - Clean Architecture implementation with strict domain separation.
   - End-to-end multi-agent screening pipeline (Evidence Extractor, Deterministic Bias Guard, Rubric Scorer, Shortlist Drafter).
   - T5 Human Review Queue product with role-based permissions (`hr_recruiter`, `hiring_manager`, `admin`), priority badges, and SLA escalation tracking.
   - Grounded Agentic RAG Copilot Chat streaming over SSE with persistent local sessions and interactive source citation cards.
   - Robust adversarial security defense achieving a 100% pass rate across 10 distinct attack vectors (prompt injection, PII extraction, demographic bias, jailbreaks).
   - Dynamic AI Control Panel with disk-persisted token ledger, live cost tracking, and model connection diagnostics.
   - Original CV viewer modal with full text formatting, skills tag expansion, and cascade deletion for vacancies and applicants.

### What Has Not Been Achieved (Pending / Deferred) ⚠️
1. **Evaluation Perfection**:
   - Live evaluation score is 0.88 / 1.00 rather than 1.00. The startup query fails due to missing seed keywords, and 6 queries achieve partial term overlap.
2. **Developer Experience & Test Isolation**:
   - `docker-compose.yml` does not bind port 5432 to `localhost`, breaking default `pytest` runs outside Docker.
   - Tests are not mounted inside the Docker API container.
   - Zero contract tests in `tests/contract/`.
   - Test suite coverage is ~35% (target $\ge 80\%$).
3. **Static Analysis Compliance**:
   - 158 `mypy` strict type errors and 32 `ruff` lint errors remain in source files.
   - Synchronous file I/O operations remain in async route handlers.
4. **Enterprise Target Infrastructure (Deferred by Design)**:
   - Enterprise API Gateway (Kong), Event Streaming (Kafka), Vault Secrets, EKS KEDA Autoscaling, Distributed Redis Caching, Dedicated Milvus/OpenSearch, Datadog APM, and Multi-Region Disaster Recovery remain target enterprise specifications deferred in the single-host MVP deployment.
5. **UI Polish**:
   - Real-time WebSocket push updates for the review queue.
   - Frontend UI trigger for PDF shortlist export.
